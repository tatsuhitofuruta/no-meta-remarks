# no-meta-remarks

AIが生成する資料・ドキュメント・スライドから「作り方の痕跡」と「水増し」を排除するClaude Code skill。

「初心者向けに書いて」と指示すると本文に「初心者向け」と書かれる。「認証だけまとめて」と頼むと「この資料では認可を扱いません」と断り書きが入る。セットアップ手順には汎用のトラブルシューティングと「CI/CDへの組み込み」案が勝手に生え、末尾には「必要に応じて調整してください」。こうした記述は、指示への応答としては自然でも、成果物としてはノイズになる。このskillはメタ表現7種と内容の水増し6種を禁止し、作成時と納品前チェックの両方で混入を防ぐ。

判定の軸は削除テスト: その文・節を削って読者の行動や理解が変わらないなら、書かない。

## 禁止パターン(1) メタ表現

| パターン | 例 |
|---|---|
| 読者・レベル指定の転記 | 「〇〇向け」「〇〇でも分かるように説明します」 |
| スコープの断り書き | 「この資料では〜を扱いません」「〜は対象外です」「〜は割愛します」 |
| 目的・構成の宣言 | 「本資料では〜を説明します」「以下の構成で説明します」 |
| 責任を読み手に返す保険 | 「必要に応じて調整してください」「あくまで一例です」 |
| 文書内の呼びかけ | 「ご不明点があればお気軽にお問い合わせください」 |
| 本文の言い換え章 | 本文を要約しただけの「まとめ」「おわりに」 |
| 中身のないスライド | 「ご清聴ありがとうございました」ページ、目次だけのページ |

## 禁止パターン(2) 内容の水増し

| パターン | 例 |
|---|---|
| 否定形の羅列 | 「〜しないでください」「〜は禁止です」を並べた注意リスト |
| 一般論の水増し | 汎用トラブルシューティング、辞書的な用語集、どの案件にも当てはまる注意事項 |
| 頼まれていない将来計画の創作 | 依頼範囲外の「CI/CDへの組み込み」案、運用スケジュール |
| 過剰な構造 | 1行の内容への見出し、1文で足りる内容の箇条書き展開 |
| 煽り・装飾 | 「インストール不要！」「👉 今すぐ試す」、絵文字付き見出し |
| 変更履歴の全量掲載 | READMEに全バージョンの変更履歴を並べる |

ユーザーが明示的に頼んだ場合と、設計書のスコープ節のようにスコープ定義自体が成果物の一部である場合は例外。詳細は [SKILL.md](SKILL.md)。

## インストール

```bash
git clone https://github.com/tatsuhitofuruta/no-meta-remarks.git ~/.claude/skills/no-meta-remarks
```

Claude Codeが成果物の作成・推敲時に自動で適用する。手動で呼ぶ場合は「メタ表現を消して」「書かなくていいことを消して」「納品前にチェックして」など。

Codex CLIでも `~/.codex/skills/` 以下に置けば同様に使える。
