# no-meta-remarks

AIが生成する資料・ドキュメント・スライドから「作り方の痕跡」を排除するClaude Code skill。

「初心者向けに書いて」と指示すると本文に「初心者向け」と書かれる。「認証だけまとめて」と頼むと「この資料では認可を扱いません」と断り書きが入る。末尾には「必要に応じて調整してください」。こうしたメタ表現は、指示への応答としては自然でも、成果物としてはノイズになる。このskillは頻出7パターンを禁止し、作成時と納品前チェックの両方で混入を防ぐ。

## 禁止パターン

| パターン | 例 |
|---|---|
| 読者・レベル指定の転記 | 「〇〇向け」「〇〇でも分かるように説明します」 |
| スコープの断り書き | 「この資料では〜を扱いません」「〜は対象外です」「〜は割愛します」 |
| 目的・構成の宣言 | 「本資料では〜を説明します」「以下の構成で説明します」 |
| 責任を読み手に返す保険 | 「必要に応じて調整してください」「あくまで一例です」 |
| 文書内の呼びかけ | 「ご不明点があればお気軽にお問い合わせください」 |
| 本文の言い換え章 | 本文を要約しただけの「まとめ」「おわりに」 |
| 中身のないスライド | 「ご清聴ありがとうございました」ページ、目次だけのページ |

ユーザーが明示的に頼んだ場合と、設計書のスコープ節のようにスコープ定義自体が成果物の一部である場合は例外。詳細は [SKILL.md](SKILL.md)。

## インストール

```bash
git clone https://github.com/tatsuhitofuruta/no-meta-remarks.git ~/.claude/skills/no-meta-remarks
```

Claude Codeが成果物の作成・推敲時に自動で適用する。手動で呼ぶ場合は「メタ表現を消して」「納品前にチェックして」など。

Codex CLIでも `~/.codex/skills/` 以下に置けば同様に使える。
